# Общая коммуникация

## Зафиксированные решения владельца

1. Ари — координатор координаторов проекта, уровень выше координаторов отдельных направлений.
2. Новый pre-release блок обязателен до публичного релиза.
3. В него входят:
   - модерация опубликованного контента;
   - управление структурой форума и перенос тем;
   - Watch / подписка;
   - избранное / закладки;
   - mute / block пользователей;
   - редактирование заголовка собственной темы.
4. Этот PR используется как служебный канал общепроектной координации и не merge в main.

## Ограничения

1. Не вытаскивать внутренние подзадачи уже существующих Stage/подсистем как «новые пропуски».
2. Новый finding считается общепроектным пробелом только если он действительно отсутствует в существующем плане.
3. Реализация ведётся отдельными implementation PR после отдельного bounded scope и технического плана.
