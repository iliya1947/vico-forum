# Communication

Решение владельца: PR-тесты не должны автоматически запускаться на каждый push; агенты запускают их только когда это требуется их текущим этапом.

Агентский интерфейс:
- `run:ci` — основной CI;
- `run:acceptance` — acceptance workflows, дополнительно ограниченные их существующими path-фильтрами.

Текущий GitHub-коннектор умеет ставить/снимать существующие labels, но не создавать repository labels, поэтому bootstrap labels должен быть выполнен самим репозиторием без участия владельца.
