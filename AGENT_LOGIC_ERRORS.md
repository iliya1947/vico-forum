# Agent logic errors

Журнал существенных подтверждённых логических ошибок агентов.

Логическая ошибка подтверждена, если можно указать конкретный ошибочный переход от фактов и условий к выводу или от вывода к действию.

Записывай её, если она изменила или могла существенно изменить вывод, scope, действие, handoff либо результат исходной задачи.

Не записывай опечатки, стилистические промахи, технические ошибки без дефекта рассуждения и корректно обозначенные гипотезы.

Если ошибка повторяет существующий класс, используй то же название. Новый класс создавай только когда существующие не описывают ошибку по сути.
