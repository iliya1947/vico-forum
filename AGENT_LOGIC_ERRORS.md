# Agent logic errors

Журнал существенных подтверждённых логических ошибок агентов.

Этот файл — долговременный общий лог в `main` только для подтверждённых логических ошибок. Локальный `AGENT_ERRORS.md` служебного PR хранит существенные ошибки конкретной задачи и архивируется вместе с этим PR; если такая ошибка является логической и подпадает под правила обоих журналов, она записывается в оба. Нелогические ошибки из `AGENT_ERRORS.md` сюда не переносятся.

Логическая ошибка подтверждена, если можно указать конкретную ошибку в трактовке задачи, отборе существенных фактов и условий либо переходе от них к выводу или от вывода к действию.

Записывай её, если она изменила или могла существенно изменить вывод, scope, действие, handoff либо результат исходной задачи.

Не записывай опечатки, стилистические промахи, технические ошибки без дефекта рассуждения и корректно обозначенные гипотезы.

Если ошибка повторяет существующий класс, используй то же название. Новый класс создавай только когда существующие не описывают ошибку по сути.
