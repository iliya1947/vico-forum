# Разбор точных 55 пользовательских правил

Источник: `USER_INSTRUCTIONS.draft.md` — точный набор из 55 правил разработчика.

Метод: каждое правило проверяется отдельно против:
- `USER_INSTRUCTIONS.current.md`;
- `PROJECT_INSTRUCTIONS.current.md`;
- `AGENTS.current.md`.

На этом этапе правила не переписываются и не объединяются. Решение о дубле принимается только если удаление не теряет ни область действия, ни аудиторию, ни отдельную защиту.

**Почему не дубль:** Project п.1 не действует вне проекта и дополнительно регулирует совместное применение двух слоёв.
