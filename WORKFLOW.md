# Workflow

## Текущий этап

Инициализация общепроектного канала Ари.

## Активная задача

Сформировать продуктовую декомпозицию нового обязательного pre-release блока из шести ранее не выделенных направлений.

## Назначения

- Общепроектный координатор: Ари.
- Технический планировщик: не назначен.
- Исполнитель: не назначен.
- Проверяющие: не назначены.
- Implementation PR/head: отсутствует.

## Ограничение Ари

Ари запрещено изменять другие PR.

## Следующий шаг

Ари определяет границы и порядок шести направлений, после чего ближайшее направление переводится в обычный bounded-цикл.
