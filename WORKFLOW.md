# Workflow

## Активный этап

Возврат на продуктовый уровень: определение пользовательского сценария управления форумом из обычного ChatGPT.

## Назначение

- Координатор и текущий исполнитель: Мира — GPT-5.6 Sol.
- Техническое планирование Лёвы приостановлено до закрытия UX/product boundary.
- Implementation PR: `#399`, ветка `feature/chatgpt-forum-control`.
- Служебный PR: `#400`, ветка `service/chatgpt-forum-control`.

## Состояние

1. Capability inventory и административный read/write scope v1 остаются полезными и не отменены.
2. Технический план Лёвы не принимается и не исправляется дальше, пока не определён пользовательский сценарий.
3. Выявлена upstream-ошибка Миры: до handoff Лёве не были согласованы UX boundaries самого продукта.
4. Site/plugin form и любой иной отдельный UI **не считаются принятым решением**.
5. `#399` остаётся пустым; реализация и CI не начаты.

## Следующий переход

Мира должна проработать с владельцем пользовательский сценарий до технической архитектуры: что означает «управлять форумом через тебя» в обычном ChatGPT, какие дополнительные UI допустимы, как выглядит подтверждение sensitive-действий, насколько GitHub/transport должен быть невидим, допускается ли выход из обычного разговора и какие действия должны выполняться по одному естественному сообщению. После фиксации этих решений обновляется product scope, и только затем задача возвращается Лёве на новый/исправленный технический план.
