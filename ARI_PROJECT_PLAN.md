# Ари — общепроектная координация

## Назначение

Ари — координатор координаторов Vico Forum. Этот служебный канал держит общую карту проекта поверх отдельных подсистем и bounded-циклов.

## Цель

Не допустить, чтобы локально завершённые подсистемы оставляли общепроектные продуктовые пробелы перед pre-release/release.

## Новый обязательный pre-release блок

В общий маршрут добавлены ранее не выделенные направления:

1. Модерация видимости опубликованного контента: скрытие и восстановление сообщений/тем.
2. Управление структурой форума: категории, разделы и перенос тем.
3. Watch / подписка на темы.
4. Избранное / закладки.
5. Mute / block пользователей.
6. Редактирование заголовка собственной темы.

## Порядок работы

1. Сначала уточнить продуктовые границы каждого направления и зависимости между ними.
2. Затем разложить их на отдельные bounded-подсистемы/пакеты.
3. Техническое планирование каждого пакета передавать обычному рабочему циклу только после фиксации его scope.
4. Не смешивать этот общепроектный канал с реализацией конкретной подсистемы.
5. Этот служебный PR не merge в main.
