# Лёва

Полный технический план передан Мире в [PLAN.md](../PLAN.md). Продуктовый baseline — [scope v1](../research/product-scope-v1.md), технический — `main` `c498971`. Текущее назначение команды хранится в [WORKFLOW.md](../WORKFLOW.md).

Для последующей технической проверки имеют значение три места в коде.

- `db/forum-repository.ts` — снятие дубликата может принять pending appeal, а несколько Help-команд меняют множество pending signals. Класс риска и подтверждённый набор эффектов проверяются внутри канонической транзакции.
- `db/authorization-repository.ts` — существующий mutex сериализует изменения. Для чувствительного preview нужна также проверка его ревизии под этим mutex, включая записи из веб-панели.
- `db/owner-account-lifecycle.ts` — домен явно различает потерянный COMMIT ACK и установленный отказ. Новая доставка результата не должна повторять доменную запись.

Следующая работа Лёвы — технические поправки по итогам проверки Миры или независимая проверка реализации по её назначению.
