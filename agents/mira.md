# Личная память Миры

Текущая цель — разложить инструкции по слоям и реально уменьшить общий объём без потери нужных защит.

Ключевая ошибка предыдущего подхода: нельзя считать «11 пунктов» компактнее «31», если каждый пункт содержит несколько независимых правил.

Нужно работать от полного инвентаря и для каждого правила принимать одно из решений: оставить в пользовательском слое, оставить/перенести в проектный слой, оставить/перенести в `AGENTS.md`, удалить как дубль/частный случай.

Не применять изменения действующих инструкций без отдельной команды разработчика.
