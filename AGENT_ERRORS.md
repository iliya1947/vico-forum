# Ошибки агентов

## E-01 — механическое «сжатие» инструкций

Что произошло: Мира уменьшила количество нумерованных пунктов, объединив несколько независимых требований в длинные составные пункты.

Почему это ошибка: фактический объём инструкций почти не уменьшился, а отдельные требования стали менее заметными и потенциально хуже исполнимыми.

Как предотвращать: при оптимизации инструкций измерять удаление семантических дублей и распределение по слоям, а не количество пунктов.
- 2026-11-21 — Мира в сообщении разработчику указала 1408 слов для 42-point User draft, хотя сохранённая карта показывала 1098. Причина: число было сообщено без сверки с только что записанным источником. Предотвращение: числовой итог в ответе брать только из фактически сохранённого результата/последнего tool output.
