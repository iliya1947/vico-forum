# Ошибки агентов

1. **2026-11-27 — Мира, преждевременный технический handoff.** Мира определила административный read/write scope, но не зафиксировала с владельцем обязательный пользовательский сценарий «управление форумом через обычный ChatGPT»: допустимость/недопустимость отдельной формы или plugin UI, видимость GitHub transport, способ подтверждения и требование оставаться в обычном разговорном потоке. Затем эта незакрытая продуктовая часть была ошибочно передана Лёве как свобода технической реализации, что позволило плану ввести Site/plugin form без решения владельца. Правильно: до архитектурного планирования отдельно зафиксировать user journey и UX boundaries, если они определяют смысл продукта.
2. **2026-11-27 — Лёва, скрытая посылка в F-01.** План считал, что `sendFollowUpMessage` даёт поддерживаемый запуск отдельного GitHub connector. Этот API публикует сообщение компонента. OpenAI требует самостоятельного выполнения публичного tool. При выборе сквозного пути проверять правила всех переходов, включая модельный вызов зависимостей. [F-01](research/plan-review-mira.md)


- 2026-11-28 — Мира повторно сделала преждевременный technical handoff: передала Лёве embedded-AI planning до утверждения владельцем двух product-scope proposal. Причина: предложения Миры были ошибочно приняты за готовый product contract. Предотвращение: если scope помечен proposal/рекомендацией, сначала по одному закрыть существенные product decisions с владельцем, только потом передавать техническое планирование.
