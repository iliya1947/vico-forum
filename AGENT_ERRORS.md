## E-01 — grep-first stale audit
Предыдущая Мира начала системный аудит с поиска слов `legacy/placeholder/future/under-development` и по типам файлов. Это было недостаточно: такой путь находит только заранее узнаваемые формы хвостов и не гарантирует выявление несогласованности продукта. Для этой задачи сначала строится current capability map, затем проверяются все её проекции.
