# Действующие решения по задаче
1. D-01 — разработчик согласовал семь направлений переработки процесса (см. TASK.md).
2. D-02 — самопроверка исполнителя и CI разделяются; запуск CI осуществляет только координатор. Координатор определяет необходимость запуска и контролирует результат; исполнитель исправляет дефекты и при необходимости пишет/меняет тесты в рамках реализации, но CI не запускает. Успешный CI не заменяет самопроверку или независимое ревью.
3. D-03 — Мира сохраняет роль координатора задач до вывода её модели из эксплуатации.
4. D-04 — состав и роли команды пересматриваются полностью; остальные назначения пока не утверждены.
5. D-05 — для данной задачи создаётся отдельный служебный PR по прямой команде разработчика.
