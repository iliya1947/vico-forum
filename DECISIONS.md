# Решения

D-01. Этот PR не merge в `main`; он используется как рабочее пространство Миры.

D-02. Предыдущие drafts, `52/52`, executability/consistency PASS и transfer package не являются основанием для новой конструкции.

D-03. Текущий первый приоритет — **починить и ужать уже действующие инструкции**, не добавляя новых требований.

D-04. Новые улучшения интеллектуальной работы и логики отложены на отдельную вторую задачу. `research/behavior-error-classes-reset.md` сохраняется как материал на потом.

D-05. Количество самостоятельных пунктов не является метрикой компактности. Самостоятельные требования нельзя склеивать или удалять ради меньшего числа пунктов.

D-06. Сокращению в первой задаче подлежат вода, повторы, лишние пояснения, неудачные формулировки и подтверждённые дубли.

D-07. Любое wording reduction допустимо только при сохранении нормативной силы, субъекта, области действия, условий, исключений и полномочий.

D-08. Действующие User Instructions являются baseline User layer. На первой задаче новые User rules не добавляются.

D-09. `*.current.md` остаются неизменяемыми снимками действующих источников. Старые `*.draft.md` остаются rejected и не используются как base.

D-10. До отдельной команды разработчика анализ в этом PR не изменяет действующие User/Project Instructions или `main:AGENTS.md`.
