## Управление из ChatGPT: границы решения

- $0 дополнительных расходов, без Work/Codex allowance и платного fallback.
- Обычный ChatGPT → приватный GitHub → Cloudflare Workers и GitHub Actions, единые канонические команды Vico, действующая авторизация и журнал действий. Worker — основной кандидат; Actions — дополнительный исполнитель и резерв доставки при доступном API, не независимый резерв Cloudflare/Neon/GitHub.
- Actions synthetic roundtrip доказан; Worker исследован по документации, live acceptance остаётся впереди. Отдельное тестовое развёртывание не требуется по решению владельца. Конкретные команды, протокол и границы безопасности определяются отдельным scope и техническим планом. Не дублировать backend и не обходить права прямым SQL.
- До внешней активации реализовать и проверить собственные границы авторизации, подтверждения чувствительных операций, защиты от повторного выполнения и недоверенного контента. Финальный security review охватывает новый канал.
- Встроенные AI-функции для пользователей/модерации, помимо уже обязательных переводов, пока исследованы, но не утверждены этим решением как обязательный объём релиза.
- Полный аудит #384 и stale/legacy #390 продолжаются в собственных каналах; выявленные дефекты классифицируются по текущей фазе и блокирующему влиянию. Назначения других команд не меняются.

## После релиза — постепенная монетизация

Это отдельный post-release backlog и не является условием первого публичного релиза.

Принципы:

1. Базовый форум и доступ к публичным знаниям остаются бесплатными.
2. Основная монетизация строится вокруг компаний и коммерческой ценности аудитории, а не продажи пользовательских данных.
3. Рекламные, партнёрские и спонсорские материалы должны быть явно обозначены.
4. Новые коммерческие механики добавляются постепенно после появления реальной аудитории и подтверждённого спроса.

Рекомендуемый порядок достройки:

1. Спонсорство форума и отдельных разделов/размещений.
2. Вакансии и поиск специалистов.
3. Партнёрские программы и affiliate-ссылки.
4. Verified/company/product pages с платными возможностями для компаний без права управлять пользовательскими отзывами.
5. Vico Pro — платные пользовательские удобства без закрытия базового контента.
6. Спонсируемые челленджи, хакатоны и другие мероприятия.
7. Marketplace для шаблонов, услуг, консультаций и других релевантных предложений с комиссией платформы.
8. Добровольная поддержка проекта через GitHub Sponsors/аналогичный механизм как дополнительный, а не основной источник дохода.
