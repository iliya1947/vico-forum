# Общепроектный рабочий план

## Назначение

Этот файл хранит общий рабочий план служебного PR #300: направления, их порядок, границы и статус. Личные выводы Ари сюда не переносятся.

## Новый обязательный pre-release блок

1. Модерация видимости опубликованного контента: скрытие и восстановление сообщений/тем.
2. Управление структурой форума: категории, разделы и перенос тем.
3. Watch / подписка на темы.
4. Избранное / закладки.
5. Mute / block пользователей.
6. Редактирование заголовка собственной темы.

## Текущий этап

Продуктовая декомпозиция шести направлений и определение их порядка относительно уже утверждённых этапов проекта.

## Правило движения

Каждое направление сначала получает продуктовые границы и место в общем маршруте. После этого ближайшее направление передаётся в обычный bounded-цикл для технического планирования и реализации отдельными implementation PR.

## Статус

Все шесть направлений приняты владельцем как нужные. Техническая реализация ещё не начата.
