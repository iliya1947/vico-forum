# План

## Задача 1 — ужать и починить действующие инструкции

1. Зафиксировать exact current baseline трёх слоёв: User / Project / `AGENTS.md`.
2. Разбирать только существующий текст; новые требования не добавлять.
3. Для каждого пункта определить:
   - самостоятельное ли это требование;
   - есть ли в нём вода, повтор, лишнее пояснение или двусмысленность;
   - дублирует ли он другой действующий пункт полностью или частично;
   - можно ли сократить формулировку без изменения смысла.
4. Самостоятельные требования не склеивать ради уменьшения числа пунктов.
5. Для каждого wording reduction отдельно сверять:
   - нормативную силу;
   - субъект;
   - область действия;
   - условия;
   - исключения;
   - полномочия.
6. Сначала подготовить компактный User draft только из действующего User baseline.
7. Затем таким же способом подготовить Project draft.
8. Затем таким же способом подготовить AGENTS draft.
9. После трёх отдельных проходов отдельно найти межслойные дубли и отделить delete-safe повторы от специализаций и повторов, необходимых из-за разной аудитории.
10. Затем проверить систему целиком:
   - не потерян ли смысл;
   - нет ли новых конфликтов;
   - действительно ли уменьшился общий объём и когнитивная нагрузка.
11. Только после этого показать разработчику exact drafts; реальные источники без отдельной команды не менять.

## Задача 2 — отложено

После завершения задачи 1 вернуться к `research/behavior-error-classes-reset.md` и отдельно рассмотреть новые общие улучшения интеллектуальной работы и логики.
