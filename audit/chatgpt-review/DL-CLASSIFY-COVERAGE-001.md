## Method

Coverage is assigned by **ID**, never by PR/task scope alone.

1. `classified+disconfirmed` requires an accepted per-record preliminary verdict plus accepted deliberate-disconfirmation coverage. An `insufficient evidence` verdict still counts as a substantive classification.
2. `reviewed-supporting` is used only where an accepted artifact explicitly treats the record as historical/factual/supporting/provenance/evidence/state material whose role was reviewed but which does not require an independent correctness verdict.
3. `unreviewed` means no exact accepted per-ID verdict or explicit supporting-role assignment could be resolved. Narrative statements such as “remaining records” do not create coverage without an exact ID map.
4. Earlier verdicts superseded by later accepted reviews remain visible as provenance, but the unique map uses only the latest accepted verdict.
