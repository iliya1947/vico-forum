## LENA-EDITOR-CLIPBOARD-LIFETIME-01 — P3 — current

A pending toolbar clipboard read is not bound to the source/operation lifetime; it can reintroduce cancelled reply content or overwrite newer local edits.

1. app/forum/markdown-editor.tsx:624–649 pasteFromClipboard awaits navigator.clipboard.readText(). Its only post-await guard is disabledRef.current; the function explicitly retains initiating render's props. It then uses captured value/authoringMode and sourceSelection(), or insertTechnicalBlock. replaceSourceRange:517–535 splices captured value and calls setValue; commitSource similarly accepts captured-source result. historyRef is live but merely records the stale replacement; it does not validate its base.

Cancel reply via views.tsx:3290 (cancelOperation and setReplyComposerOpen(false)). cancelOperation invokes cancelEditing (markdown-editor.tsx:281–289,856–890), resets Markdown/history to empty default and resets selections; attachment cancellation is separate. Reply disabled prop :3297 remains isReplySubmitting (false). editorScope (account/context/locale) is unchanged; neither cancel nor scope reset invalidates clipboard request.
