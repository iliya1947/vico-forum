## Verified source paths and observations

No global mutable request session found here. Content-generation runtime explicitly disabled; no queue handler/provider activation. Outer failure handling is specialized to Owner paths; regular unexpected exceptions propagate.
2. workers/database-bindings.ts, wrangler.jsonc (full): distinct named localization and web bindings; missing/blank string fails rather than falling back to another role. HEAD document response has no body. SSR has 5s stream timeout with 6s abort and waits allReady before returning; no claim about observed time-to-first-byte. Degraded registry fallback and resource contracts remain A6. Header authorization/notification reads handle classified outages separately; unexpected errors propagate.
5. app/administrative-routing/{addresses.ts,provider.tsx,request-context.ts} (full): independent typed outgoing address families with encoded dynamic segments, static default same-origin, replaceable per tree/request. Not an ingress/authorization mechanism; isolated Owner runtime is deferred, not a defect.
