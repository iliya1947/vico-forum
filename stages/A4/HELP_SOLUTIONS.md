## New independent finding LENA-HELP-01 — Low/P3 (preliminary)

Attention presents a non-actionable duplicate signal as actionable when its proposed canonical original has been hidden.
1. Current UI_UX_PASS.md 368–375: Signals groups display actionable individual submissions with target links and Accept/Reject. ADMIN_PANEL.md 629–638 explicitly preserves pending signals on Hide, but prohibits ordinary review with hidden dependencies; own withdrawal exception remains. This is not a requirement to bypass visibility or discard a retained signal.
2. db/forum-repository.ts readHelpAttentionCounts 2605–2638 and readHelpAttentionCases 2690–2730: pending signal filter checks primary topic visibility and optional answer visibility, but proposed original only left joined with isHidden=false for masking, not admission. Duplicate whose primary topic remains visible and original is hidden stays in duplicate and potentially Mixed queue/count. Returned original=null, no hidden original ID/title (correct privacy). 
3. app/routes/attention.tsx 166–174 forwards cases; app/forum/views.tsx 1755–1780: missing original gets special unavailable explanation only for appeal, not signal; signal still gets both enabled action buttons, disabled only for preview or pending request. Authorized reviewer with no request in flight can click either. 
4. Both server paths deliberately deny review: rejected branch resolveHelpSignal 4099–4138 calls lockVisibleHelpSignalDependencies (4028–4052); accepted branch 4140–4193 locks sorted dependencies and rejects any hidden topic. attention.tsx 245 invokes same service; runForumMutation maps ForumEntityNotFoundError to 404. Neither action can resolve the case until original restored. This is an inconsistent affordance/queue contract, not an authorization bypass. 
5. Existing tests independently demonstrate exact compatible state: tests/database/moderation-visibility-commands.test.ts 3250–3298 expects retained masked duplicate case and unchanged counts after Hide of proposed original; 752–768 expects reject denied, author withdrawal allowed. These tests were read, not executed. Both persistence/masking and rejection are intentional; defect is presenting an unreviewable retained signal as actionable without explanatory state. Preserve retention and privacy. Whether to exclude non-actionable cases or display an explicit unavailable state is a product/technical decision, not made by audit.
6. Distinct from LENA-MEASURE-01 (AP-10 authority filtering after pagination), and from PUBLIC-PROJECTION-01 (private flags). No matching finding in #315 D8 selected review; #342 scope is unrelated. Proposed acceptance: hidden original, visible duplicate signal, actual queue presentation clearly non-actionable, no hidden original data, no mutation; after Restore normal review available. No new browser evidence.
