# Задача

Рабочий PR Миры для перепроектирования слоёв инструкций ChatGPT в проекте Vico Forum.

## Исходная цель

Получить минимальную, понятную и исполнимую систему инструкций, которая реально улучшает качество мышления и работы агентов и уменьшает количество тупых решений.

## Текущий приоритет

Работа разделена на две последовательные задачи.

### Задача 1 — сначала починить действующие инструкции

Сначала привести в нормальный рабочий вид **то, что уже существует**, без добавления новых требований:

1. Ужать действующие User Instructions, Project Instructions и `AGENTS.md` за счёт удаления воды, повторов, лишних пояснений и неудачных формулировок.
2. Не удалять и не склеивать самостоятельные требования только ради меньшего количества пунктов.
3. Не менять смысл, нормативную силу, область действия, исключения и полномочия существующих правил без отдельного доказанного основания.
4. Не переносить новые идеи из будущего интеллектуального улучшения в этот этап.
5. Итог первой задачи должен быть короче, яснее и легче исполним, при сохранении реально действующих требований.

### Задача 2 — потом улучшать интеллектуальную работу и логику

После завершения первой задачи отдельно вернуться к карте требуемого поведения и реальных ошибок и определить, какие **новые** общие улучшения интеллектуальной работы и логики действительно нужны.

Материал `research/behavior-error-classes-reset.md` сохранён для этой второй задачи и сейчас не является основанием для расширения действующих инструкций.

## Целевая архитектура

1. **User Instructions** — глобальные правила пользователя, применимые во всех чатах и проектах.
2. **Project Instructions** — правила, специфичные для проекта Vico Forum и работы ChatGPT в нём.
3. **AGENTS.md** — общий рабочий регламент команды и репозитория для ChatGPT/Codex.

## Жёсткие правила для User Instructions

1. Всё, что уже находится в действующих User Instructions, считается исходным пользовательским baseline.
2. На первой задаче новые правила в User Instructions не добавляются.
3. Самостоятельные пункты не сокращаются и не склеиваются ради количества.
4. Компактность достигается удалением воды, повторов и вводящих в заблуждение пояснений при сохранении смысла.

## Границы

- анализировать инструкции, их формулировки, применение, дубли и распределение по слоям;
- не менять продуктовый код, архитектуру форума, CI, production или implementation PR;
- предыдущие rejected drafts и PASS-метрики не использовать как исходную конструкцию;
- не изменять действующие User/Project Instructions или `main:AGENTS.md` без отдельной прямой команды разработчика.

## Критерий готовности первой задачи

1. Все три действующих слоя разобраны от current baseline.
2. Убрана подтверждённая вода и дубли.
3. Самостоятельные требования сохранены отдельными и заметными.
4. Для каждого сокращения сохранены смысл, модальность, субъект, область и исключения.
5. Итог реально короче и яснее current baseline.
6. Новые интеллектуально-логические требования не добавлены.

## Особый статус PR

Этот PR — рабочее пространство для анализа и фиксации материалов. Он не предназначен для merge в `main`.
