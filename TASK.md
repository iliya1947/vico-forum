# Задача

Рабочий PR Миры для системного разбора слоёв инструкций ChatGPT в проекте Vico Forum.

## Цель

Получить компактную и исполнимую архитектуру инструкций без механического сжатия текста и без дублирования требований между пользовательским слоем, проектными инструкциями и `AGENTS.md`.

## Границы

- анализировать только инструкции, логику их применения, дубли и распределение по слоям;
- не изменять продуктовый код, архитектуру форума, CI, production или текущие implementation PR;
- не переносить проектные/GitHub-specific правила в пользовательские инструкции без необходимости;
- не изменять сами действующие инструкции проекта без отдельной прямой команды разработчика.

## Особый статус PR

Этот PR — рабочее пространство для анализа и фиксации материалов. Он не предназначен для merge в `main`.

## Критерий готовности

Есть проверенная карта: что оставить в пользовательских инструкциях, что оставить/усилить в проектных инструкциях, что оставить/изменить в `AGENTS.md`, что удалить как дубль; для каждого изменения понятна причина и не потеряна требуемая защита.
